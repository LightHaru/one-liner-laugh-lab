A dependency-free Node 22.18+ program that writes one short funny line — the excuse a robot vacuum gives after eating a sock — to `/output/entry.txt`.

## Run it

```sh
node main.ts            # writes /output/entry.txt
node main.ts ./out      # or a directory of your choice for local runs
node --test             # smoke test
```
